# Klar – To-Do

Persönliche To-Do-PWA (Liquid-Glass-Design) mit Heute-, Wochen-/Monats- und „Alles offen“-Ansicht, Listen,
wiederkehrenden Aufgaben, Terminen, Erinnerungen und Sprachnotizen mit Live-Text.
Alle Daten liegen ausschließlich lokal auf dem Gerät (IndexedDB). Kein Server, kein Tracking.

Installieren: Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“.

Update ausrollen: `CACHE`-Version in `sw.js` und `VERSION` in `js/app.js` hochzählen, dann pushen.
